# Pr-stamo

## Sistema de Control de Préstamos

Aplicación diseñada para facilitar el registro y control de préstamos, permitiendo organizar la información de los usuarios, préstamos y pagos de manera sencilla.

## Funcionalidades

- Registro de préstamos.
- Control de clientes.
- Registro de pagos.
- Consulta del estado de los préstamos.
- Organización de la información.
- Seguimiento de saldos pendientes.

## Archivo principal

El proyecto incluye el archivo:

`control_prestamos_v1.zip`

Este archivo contiene la versión actual del sistema.

## Objetivo

Facilitar la administración y seguimiento de préstamos mediante una herramienta sencilla y organizada.
